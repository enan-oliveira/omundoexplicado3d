Política de Privacidade

Última atualização: 17 de novembro de 2026.

Esta política vale para o "Publicador videos-3d", ferramenta de uso interno do canal O Mundo Explicado 3D.

O que a ferramenta faz

Publica e agenda vídeos do próprio canal nas contas do canal no YouTube, no Facebook (Página), no Instagram e no TikTok, usando as APIs oficiais dessas plataformas. Ela é usada só pelo dono do canal e não está disponível para outras pessoas.

Dados acessados

  • Tokens de acesso às contas do próprio canal, concedidos pelo dono do canal no login oficial de cada plataforma.
  • Dados públicos e estatísticas dos vídeos do próprio canal (por exemplo, link e número de visualizações), para conferir as publicações.

A ferramenta não coleta, não vende e não compartilha dados de outras pessoas: não lê mensagens, não guarda dados de espectadores e não usa dados para publicidade.

Onde os dados ficam

Os tokens ficam guardados apenas no computador do dono do canal, num arquivo local que não é publicado. Os dados de uso do YouTube seguem também a Política de Privacidade do Google e os Termos de Serviço do YouTube. O uso das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

  • Google/YouTube: myaccount.google.com/permissions.
  • Facebook e Instagram: Configurações → Integrações comerciais.
  • TikTok: Configurações e privacidade → Segurança → Gerenciar permissões de apps.

Para pedir a exclusão de qualquer dado, veja a página Exclusão de dados.
